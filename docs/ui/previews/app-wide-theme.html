Performance contract

Draw phase only

Brushes built in drawWithCache; animated values read in onDrawBehind. A frame invalidates draw — never composition or layout.

Zero per-frame allocation

Backdrop: 1 rect + 4 circles under a translate. Orb: 1 glow, ~3 rings, 1 body, 1 highlight, 1 core. Smoothing lives in a plain class, not snapshot state.

Respects the system

rememberMotionAllowed() off → one static frame, no rings. Voice clock stops outside RESUMED, so a backgrounded screen costs nothing.
